# Jarvis Project Roadmap 🚀

This roadmap outlines the planned evolution of **Jarvis for macOS** into the ultimate native command center for developers and power users.

---

## 🎯 Current Milestone: v1.0.x (Foundation & Community)
- [x] Native SwiftUI & AppKit dashboard with OLED dark palette
- [x] Floating HUD widget with dynamic positioning
- [x] Local-first data persistence (`~/Library/Application Support/Jarvis`)
- [x] Live Claude Code (`5h` / `Weekly`) quota tracking
- [x] Live OpenAI Codex sliding window tracking
- [x] Local offline AI assistant via Ollama (`127.0.0.1:11434`)
- [x] Orbit subscriptions manager with live ECB currency conversion
- [x] Pet expenses tracker with JSON import/export
- [x] Automated DMG release pipeline via GitHub Actions
- [x] Open source MIT license and contribution guidelines

---

## ⚡ Near-Term: v1.1.0 (Workflow & Speed)
- [ ] **Global Hotkey Daemon:** Configurable system-wide shortcut (e.g. `⌥ + Space`) to summon/hide the floating HUD widget from anywhere.
- [ ] **Expanded AI Quota Adapters:**
  - OpenRouter usage & credits tracking
  - DeepSeek API balance & rate-limit indicators
  - GitHub Copilot usage status
- [ ] **Enhanced Assistant Context:** Ability for the assistant to query local file shortcuts directly from natural language.
- [ ] **Official Homebrew Formula:** Support `brew install --cask jarvis`.

---

## 🔮 Future Milestones: v2.0 (Ecosystem & Extensions)
- [ ] **Plugin System:** Lightweight JSON/Script plugins for custom status tiles in the floating widget.
- [ ] **Calendar & Meeting HUD:** Glanceable countdown to the next scheduled meeting in the floating bar.
- [ ] **Custom Themes:** User-selectable accent themes (Cyberpunk Amber, Matrix Green, Midnight Blue).
- [ ] **Full Menu Bar Quick Menu:** Interactive mini-dashboard directly inside the `NSStatusItem` popover.
